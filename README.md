# FaceClaw - a PNG Face Web Scraper

## Description
This WebScraper is a prototype and was developed as a support software for a PhD project.
The project was researching facial emotion recognition while wearing VR gear.

This WebScraper is scraping the internet for images with the users input. The user can choose a saving directory and the amount of images to scrape for. The user can also choose to activate the Face Detection to filter images without faces in it. The Webscaper uses the Chrome Browser automatically and will close it after the Scraping process is finished. The images and a log file will be saved into
the prefered location.

> [!CAUTION]
> This is a prototype and is not meant for private usage. Scraping for images can violate the owners rights.  
> I strongly advise not to use this software.

## Requirements
1. Runtime Environment: Java JDK 20  

2. Frameworks: 
    - Selenium Java SDK (Version 4.9.0)
    - OpenCV (Version 4.12.0)  
3. Models: YuNet Face Detection 2023 - https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet
5. Chrome Browser  
6. Chromedriver (Same version as Browser) - https://sites.google.com/chromium.org/driver/downloads
